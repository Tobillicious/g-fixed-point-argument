## Review rules
1. Find before build; do not weaken theorem statements or silently change definitions.
2. Distinguish Lean kernel theorems, explicit axioms, hypotheses, physical interpretation, and empirical evidence.
3. Trace `BCRDIsQG` backward to every defining field. Test whether any desired consequence is assumed.
4. Check complete subject-level meaning, nonvacuity, physical-event coverage, continuation and authentic original-six X3 preservation.
5. Treat God, Good, Guardian, Gravity, and G as distinct propositions unless identity bridges are actually proved.
6. Record positive and negative countermodels, exact source refs, and reproducible build results.
7. Preserve the original upstream source. No merges into upstream.
